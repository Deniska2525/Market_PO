# Развёртывание

Локальный запуск описан в [README](../README.md), размещение на Render без домена: [RENDER.md](RENDER.md).
Ниже: требования к своему серверу и безопасность.

## Характеристики сервера (малая нагрузка, до 1 тыс. визитов в день)

Это оценка по составу контейнеров, замеров на реальной машине не делалось. LLM для подбора вызывается во
внешнем API, GPU не нужен.

| | Минимум (демо) | Рекомендуется |
|---|---|---|
| vCPU | 1 | 2 |
| RAM | 2 ГБ + 2 ГБ swap | 4 ГБ |
| Диск | 25 ГБ SSD | 40–60 ГБ NVMe SSD |
| Канал | 100 Мбит/с | 100–200 Мбит/с, от 1 ТБ трафика в месяц |

Ориентировочная память в работе: PostgreSQL 150–300 МБ, backend (один процесс uvicorn) 200–300 МБ,
nginx до 20 МБ, ОС и Docker 0,5–0,8 ГБ, итого около 1–1,5 ГБ. Диск считайте от объёма изображений
(лимит 5 МБ на файл) плюс запас на резервные копии.

Нужно на сервере: Ubuntu 24.04 LTS (или Debian 12), Docker Engine и плагин Compose, домен.

## Чек-лист перед публикацией в интернет

- [ ] Свои значения `SECRET_KEY`, паролей и `FRONTEND_URL`; `ENV=production`.
- [ ] Первый суперадмин: переменные `SUPERUSER_USERNAME`, `SUPERUSER_EMAIL`, `SUPERUSER_PASSWORD`;
      демо-аккаунты в production не создаются (если не задано `SEED_DEMO_USERS=true`).
- [ ] HTTPS: контейнер frontend отдаёт только HTTP, поэтому перед ним нужен reverse proxy с сертификатом
      (Caddy проще всего, либо Traefik или certbot). Без HTTPS в production не заработает вход (cookie Secure).
- [ ] Порты: наружу только 80, 443 и 22 (по ключам). В `docker-compose.yml` порты уже привязаны к `127.0.0.1`;
      для сервера за reverse proxy проксируйте на них, порт базы наружу не публикуйте.
- [ ] Адрес API: фронтенд собирается с адресом бэкенда `http://localhost:8000` по умолчанию. Для сервера задайте
      `VITE_API_BASE_URL` при сборке образа (build-аргумент) или проксируйте `/api/` через nginx.
- [ ] Резервные копии: ежедневный `pg_dump` и копия `backend/data/media`, хранить вне сервера, проверять восстановление.
- [ ] Ключ нейросети: бесплатный тариф или лимит расходов у провайдера (поиск уже ограничен 10 запросами в минуту).
- [ ] Модерация и политика конфиденциальности: на сайте собираются имена, email и телефоны из заявок.

## Известные ограничения

- Нет уведомлений по email: заявки видны только в кабинете сотрудника.
- Нет антивирусной проверки загрузок (загружаются только изображения, тип проверяется по содержимому).
- Миграции схемы: `schema_sync.py` добавляет недостающие колонки, но не удаляет и не меняет существующие.
  Для постоянной эксплуатации стоит перейти на Alembic.
- Фильтрация и поиск по каталогу выполняются в Python по опубликованным карточкам: для сотен карточек достаточно,
  для тысяч нужны полнотекстовый индекс или векторный поиск.
